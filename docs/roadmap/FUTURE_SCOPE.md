# Future Scope

Capabilities confirmed as later work. They must be considered in analysis and design so they do not become impossible, but they must not be implemented during MVP.

---

- Custom domain tenant resolution
- Custom email sender
- Webhooks
- Broader usage metering
- Support impersonation with visible audit
- First-class shipment consolidation workflow
- CSV export
- Document versioning
- Richer billing operations once commercial plans are finalized

## Architecture Watchpoints

When designing MVP data models, keep these extension points possible:

- Master / house shipment relationship
- Manual vs external vs GPS tracking events
- Feature entitlements for later modules
- Multi-membership users
- Exchange rates
- File metadata that can later support versioning
- Event-driven notifications that can later add channels
