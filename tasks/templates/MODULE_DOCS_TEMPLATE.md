# Module Documentation Set

Create this set under `docs/modules/<module-name>/` only when the module enters Analysis.

Do not create all module folders in advance.

Required files:

- `OVERVIEW.md`
- `REQUIREMENTS.md`
- `BUSINESS_RULES.md`
- `USER_FLOWS.md`
- `DATA_MODEL.md`
- `API.md`
- `PERMISSIONS.md`
- `EDGE_CASES.md`
- `TESTING.md`
- `CHANGELOG.md`

Fill only the files needed by the current phase. Empty speculative API contracts are not required during Analysis.
